# Architecture Decision Records (ADR)

Version: v0.1.0

Status: Stable

---

## Overview

This directory contains the important architectural decisions made during the development of AIHub Backend.

Instead of relying on assumptions or tribal knowledge, every major technical decision is documented here.

These records explain:

- Why a decision was made
- What alternatives were considered
- What the consequences are
