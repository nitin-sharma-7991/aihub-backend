# PostgreSQL Setup

Version: v0.1.0

Status: Stable

---

## Install PostgreSQL

Download PostgreSQL from the official website.

Install:

- PostgreSQL Server
- pgAdmin 4

---

## Create Database

```sql
CREATE DATABASE aihub;
```

---

## Default Configuration

| Property | Value |
|----------|---------|
| Host | localhost |
| Port | 5432 |
| Database | aihub |

---

## Verify Connection

Open pgAdmin and verify that the `aihub` database exists before running the application.
