# Installation Guide

Version: v0.1.0

Status: Stable

---

## Requirements

- Go 1.25 or higher
- PostgreSQL
- Git

---

## Clone Repository

```bash
git clone <repository-url>

cd aihub-backend
```

---

## Install Dependencies

```bash
go mod tidy
```

---

## Verify Installation

```bash
go version
```

Expected output

```
go version go1.25 windows/amd64
```
